# PinToStay 웹앱 (CLIP 이미지 유사도 프로토타입)

사진을 업로드하면 CLIP 이미지 임베딩을 추출하고, 사용자 선호 사진 여러 장의 평균 벡터와 관광자원 사진의 코사인 유사도를 비교하는 Flask 웹앱입니다.

## 1. 필요한 것
- Python 3.10 이상 권장
- 인터넷 연결 (최초 실행 시 CLIP 모델 파일 다운로드)
- 사진 파일 몇 장

## 2. 설치 및 실행 (Windows)
1. ZIP 압축을 풉니다.
2. 압축을 푼 `pintostay_webapp` 폴더를 엽니다.
3. 폴더 주소창에 `cmd`를 입력하고 Enter를 눌러 명령 프롬프트를 엽니다.
4. 다음 명령어를 순서대로 실행합니다.

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

5. 터미널에 서버 실행 주소가 나타나면 브라우저에서 `http://127.0.0.1:5000` 을 엽니다.
6. 왼쪽에는 선호 사진을 1장 이상, 오른쪽에는 관광자원 후보 사진을 1장 이상 업로드하고 **AI 유사도 분석하기**를 누릅니다.

## 3. macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```
브라우저에서 `http://127.0.0.1:5000` 을 엽니다.

## 4. 작동 방식
- 사용자 선호 이미지마다 CLIP 이미지 임베딩을 추출합니다.
- 임베딩 벡터들을 평균 내고 정규화해 사용자 대표 벡터를 만듭니다.
- 각 관광자원 이미지의 임베딩을 추출합니다.
- 사용자 대표 벡터와 관광자원 벡터 간 코사인 유사도를 계산하고 높은 순서로 정렬합니다.

## 5. 해석 시 주의사항
- 코사인 유사도는 취향 일치율(%)이나 추천 정확도가 아닙니다.
- 현재 앱은 사용자가 올린 관광자원 이미지끼리 비교합니다. 실제 지역 관광지 검색, 운영시간, 거리 계산, 체류 일정 생성은 포함하지 않습니다.
- 이미지 업로드는 분석 요청 중 메모리에서 처리하며, 별도의 영구 저장 기능은 구현되어 있지 않습니다.
- 연구용 프로토타입입니다. 공개 배포 전에 보안, 개인정보 보호, 업로드 제한, 운영환경 설정을 추가로 검토해야 합니다.

## 문제 해결
- 최초 실행은 모델을 다운로드하므로 시간이 걸릴 수 있습니다.
- `python` 명령이 작동하지 않으면 Python 설치 여부를 확인하고, Windows에서는 `py` 명령을 사용할 수 있습니다.
- 포트 5000이 이미 사용 중이면 app.py의 마지막 줄을 `app.run(host="127.0.0.1", port=5001, debug=False)` 로 바꾸고 `http://127.0.0.1:5001` 로 접속합니다.
